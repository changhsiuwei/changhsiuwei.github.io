這幾年大家在日常工作或學習中使用 AI，大多習慣在瀏覽器的對話框裡輸入提示詞（Prompt），請模型幫忙查資料或寫草稿。不過在商業、財務與會計審計的應用場景中，AI 正在經歷一次很重要的轉變——從過去單純的「問答聊天」，走向能夠自主規劃步驟、操作工具、執行驗證的「自主代理人（AI Agent）」。

在會計資訊系統的研究與教學中，我們非常重視資料的真實性、內部控制與安全性。如果我們希望讓 AI 實質協助處理財務數據、核對跨期報表或是編寫自動化腳本，第一步不是急著寫提示詞，而是要在自己的電腦裡，搭建好一套安全、受控且能順暢運行的工具環境。

很多同學與實務界的朋友向我反映，剛開始接觸這些工具時，最容易卡關的往往就是「環境建置」。例如終端機指令不熟悉、套件相依性衝突、環境變數設錯，或是不知道該如何妥善保管自己的 API 金鑰。為了讓大家在起步時少走一些冤枉路，我把這學期課程第一週的環境建置流程，整理成了一套完整的教學教材，並特別錄製了一部詳細步驟的實機安裝教學影片，把所有資料整理公開，歡迎大家參考與取用。

**這次的環境建置主要包含哪些內容？**

本單元的核心在於帶大家建置一套完整的「三層代理人工具鏈」與「金鑰安全防線」：

**桌面操作代理人（GUI Agent）：**

以 Hermes Desktop 為例，帶大家安裝能「看懂螢幕」並模擬滑鼠鍵盤操作的桌面代理人，了解如何讓 AI 在受控的環境下協助操作一般桌面軟體。

**終端機代理人（CLI Agent）：**

以 Pi Coding Agent 為例，部署在命令列終端裡運行的輕量工具，適合用來做程式碼審查、批次處理與自動化腳本執行。

**現代化 AI 開發環境（Agentic IDE）：**

介紹適合管理複雜工作流、具備上下文感知能力的程式碼編輯環境。

**API 金鑰安全管理與成本控制：**

教大家如何把 Google AI Studio、OpenAI、Anthropic 與 DeepSeek 等 API 金鑰，妥善保存在本地的加密保險箱中，避免誤傳到公開網路造成資安風險；同時也會聊聊使用各家模型時的費用結構，建立健康的成本管理觀念。

**整理給各位的學習資源**

為了讓不同習慣的朋友都能順暢上手，我準備了三種互補的材料：

**步驟詳解操作錄影：**

我把從零開始的安裝過程全程錄了下來。從軟體下載、路徑與指令輸入、套件安裝，到最後成功跑通第一個測試，每個環節都有操作畫面與聲音說明。如果在安裝時遇到常見的報錯，影片中也有示範排解方式，大家可以隨時暫停、跟著一步步操作。

**完整授課簡報：**

整理了 AI 代理人的觀念演進、架構技術棧，以及超過 70 張清晰的操作介面圖解，適合先瀏覽一遍，快速建立整體概念。

**圖解實作講義手冊：**

將安裝流程化為如同操作手冊般的步驟指引，標明每個動作該點哪裡、該輸入什麼指令，以及需要注意的細節，方便大家在實作時隨時翻閱對照。

**歡迎自由取用與交流**

這套教材的初衷就是希望把技術門檻降下來，讓更多想嘗試 AI 代理人應用的朋友，能有一個乾淨、清楚且安全的起點。

無論是正在修課的同學、想在課堂中補充實作環境的教學同仁，或是對新技術感興趣的專業先進，所有教材、簡報與錄影都歡迎自由下載、參考與轉發。如果教師同仁有教學需要，也十分歡迎直接拿去使用。

如果在安裝過程中遇到任何相容性問題或疑問，歡迎隨時留言交流，我也會持續將大家的回饋補充進講義中。祝大家環境建置順利！
