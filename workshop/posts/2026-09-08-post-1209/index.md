各位師長、學界同仁、同學與專業先進，您好：

我是國立臺北大學會計學系的張修瑋。

隨著人工智慧技術的發展，應用型態已逐漸由單向對話的提詞工程（Prompt Engineering），延伸至具備自主規劃、多步驟驗證與工具調用能力的代理人系統架構（Agentic AI）。在會計審計與企業資訊系統的研究與教學情境中，資料的可驗證性、內部控制界限以及機敏資訊的治理，始終是導入任何運算技術時的核心考量。若要使人工智慧系統能夠實質協助財務報表勾稽、底稿分析或跨期數據查核，建立一套合規、受控且具備安全治理外框（Harness）的本地工作環境，是不可或缺的基礎工程。

本學期《會計資訊系統》第一週課程著重於「環境建置與自主代理人工具鏈」。考慮到在跨平臺安裝、相依套件部署、終端機命令列操作以及權限配置過程中，學習者往往需要耗費大量時間排查系統環境衝突，因此我將本單元的完整建置歷程進行了標準化整理，並錄製了實機操作解說影片，連同課程簡報與講義手冊一併公開，提供感興趣的同仁與同學參考取用。

**本次環境建置涵蓋之技術架構**

本單元所建立的實作環境，主要圍繞三層代理人工具鏈與本地金鑰安全治理體系：

1. **三層代理人工具鏈（Tri-Tier Toolchain）**：
    * **桌面圖形介面代理人（GUI Agent）**：以 Hermes Desktop 為例，配置具備螢幕感知與鍵鼠操作模擬能力的代理人環境，說明如何在沙盒化邊界內輔助辦公應用軟體的操作。
    * **終端命令列代理人（CLI Agent）**：以 Pi Coding Agent 為例，部署輕量級程式碼審計與腳本執行環境，用於自動化測試與管線編排。
    * **整合開發環境（Agentic IDE）**：建立具備上下文感知與多任務編排特性的現代化工作台。
2. **主權金鑰治理與運算成本控制（Sovereign Key & Token Economics）**：
    * 建立本地加密憑證管理機制，說明 Google AI Studio、OpenAI、Anthropic 及 DeepSeek 等 API 金鑰之安全綁定流程，防範原始碼版本控制中的金鑰外洩風險。
    * 分析大語言模型的 Token 計費架構與快取策略，協助學習者建立企業級成本評估思維。


**隨附教學資源說明**

為方便不同需求之學習與教學使用，相關材料整理如下：

1. **實機安裝步驟錄影**：全程錄製自系統初始狀態至工具鏈部署完成的完整過程，包含終端命令輸入、環境變數設定、套件依賴性排解與各代理人模組之連通性驗證，提供逐步跟練之參考。
2. **課程授課簡報（131 頁）**：採 16:9 Beamer 規格編撰，收錄人工智慧發展脈絡、現代八層技術棧結構、三層架構原理及超過 70 處操作流程圖解。
3. **實作講義手冊（33 頁）**：提供詳細的步驟說明（Action Steps）、系統原理摘要（System Rationale）與常見安裝錯誤之排錯流程（Troubleshooting SOP），所有成對圖表均依學術出版標準進行幾何對齊。
